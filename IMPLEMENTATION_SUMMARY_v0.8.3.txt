Sonic Refiner v0.8.3

Base: validated v0.8.3-dev.2 source, itself based directly on official v0.8.2.

Purpose:
- Align Sonic Refiner display-language behavior and wording with R128 Real-time Loudness Normalizer.

Changes from v0.8.2:
- Adds Automatic (Windows) / 自動（Windows） alongside Japanese / English.
- Automatic follows the Windows UI language: Japanese for Japanese Windows UI, English otherwise.
- Manual Japanese / English selections override Automatic.
- New installations default to Automatic; existing saved manual ja / en choices are preserved.
- Language preference remains saved separately from DSP presets.
- Japanese settings label is 表示言語：.
- English settings label is Display language:.
- Top-row layout adjusted so the English label is not clipped.

- Immediate Japanese / English switching passed.
