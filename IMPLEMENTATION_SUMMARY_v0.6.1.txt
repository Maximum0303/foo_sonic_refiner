Sonic Refiner v0.6.1 implementation summary

Purpose
- Prevent previous playback-position Auto Low / Auto High values from appearing to be fresh completed analysis after playback changes.
- Show a clear analyzing state while new ATB history is being accumulated.

Implementation
- Retains the v0.6.1-dev.2 runtime-only playback callback / discontinuity generation approach.
- on_playback_new_track and on_playback_seek signal a runtime-only generation change.
- The ATB processor consumes unseen generations and resets analysis for the new playback position.
- Playback start, track changes, seeks, Stop -> playback and ATB Off -> On enter the analysis-pending UI state.
- Pause -> Resume preserves analysis.
- Numeric Auto Low / Auto High status returns after sufficient fresh analysis.

Compatibility
- No serialization changes.
- SRP4 unchanged.
- preset_version 9 unchanged.
- 12 built-in presets unchanged.
- ATB Low / High decision algorithm, mapping, smoothing, startup protection and +10 dB limits unchanged.
- Legacy DSP preset / SRP1 / SRP2 / SRP3 / SRP4 compatibility unchanged.
- Runtime analyzer state remains non-persistent.

Validation
- Verified on v0.6.1-dev.2: playback start, Next, Previous, direct jump, seek, natural track advance, Stop -> playback, ATB Off -> On, Pause -> Resume, analyzing -> numeric transition, Japanese/English, Light/Dark, and full-track playback.

Formal version
- 0.6.1
