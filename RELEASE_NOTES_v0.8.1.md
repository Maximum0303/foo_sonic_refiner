# Sonic Refiner v0.8.1 Release Notes

## English

v0.8.1 is the formal documentation and user-guidance refresh based on the official v0.8.0 audio-processing baseline. Audio processing is intentionally unchanged.

### Changed

- Help now recommends **R128 Real-time Loudness Normalizer: Natural -18** as the normal starting point.
- Stale Help wording was refreshed for Preset Manager Backup / Restore, Reverb, and A/B behavior.
- Help and Glossary distinguish the four standard normalization presets from the three additional mastering presets.
- Important Notes now also identifies Natural -18 as the recommended R128 starting point.
- QUICK_START.md and README_FIRST.txt are refreshed for Reverb, 16 built-in presets, Preset Manager, SRP5, and `preset_version 10`.

### Compatibility

- No DSP algorithm changes.
- No Reverb tuning or built-in preset value changes.
- SRP5 and `preset_version 10` are unchanged.
- Legacy SRP1-SRP4, DSP preset versions 1-9, and older `.srpbackup` compatibility are unchanged.

## 日本語

v0.8.1は、正式v0.8.0の音声処理を維持したまま、ユーザー向け説明・文書を現行仕様へ整備した正式版です。音声処理は意図的に変更していません。

### 変更点

- Helpで **R128 Real-time Loudness Normalizer「ナチュラル -18」** を通常の基本推奨として明記。
- Help内の旧表記をPreset Managerのバックアップ／復元、Reverb、A/Bの現行仕様へ更新。
- Help／用語集で、標準ノーマライズ4種と追加マスタリング3種の違いを明確化。
- 注意事項にも「ナチュラル -18」をR128側の基本推奨として追記。
- QUICK_START.md／README_FIRST.txtをReverb、16内蔵プリセット、Preset Manager、SRP5、`preset_version 10`の現行仕様へ更新。

### 互換性

- DSPアルゴリズム変更なし。
- Reverb調整値・内蔵プリセット値変更なし。
- SRP5／`preset_version 10`変更なし。
- SRP1～SRP4、DSP preset version 1～9、旧`.srpbackup`互換変更なし。
