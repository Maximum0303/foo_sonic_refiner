Sonic Refiner v0.3.0
Japanese / English UI release

Implemented:
- Japanese / English language selector in the 560 x 320 settings dialog
- First-run default based on the Windows display language
- Persistent language preference stored separately from DSP presets
- Immediate UI switching without notifying or rebuilding the DSP
- Localized labels, buttons, built-in preset names and status display
- Localized user-preset dialog, confirmations, errors and completion messages
- Localized export/import file dialogs
- Localized Help, Glossary, Important Notes and License pages
- English-first README and package documentation

Compatibility retained:
- DSP processing implementation unchanged from v0.2.0
- preset_version 8
- SRP3 write format
- SRP1 / SRP2 / SRP3 read compatibility
- .srpbackup format
- Existing UTF-8 user-preset names
- Built-in preset values and order
- Settings dialog size 560 x 320

Not included:
- A/B comparison slots (deferred to a later version)

Validation completed:
- Visual Studio 2022, Release / x64 build and packaging confirmed
- Runtime checks recorded in TESTING_v0.3.0.md

- ヘルプ、用語集、注意事項、ライセンスを英語化
- READMEとパッケージ文書を英語先・日本語後へ変更
